## DiPlay android-4.2.2 分支 CarPlay 有线/无线支持性分析
- 用户问"当前分支是否支持有线无线 CarPlay"。先读 README 给了结论，后要求**仅源码、不读文档**深度分析。
- 证据链：设置三态 `DefaultConnectionMode`（DiPlayBootstrap.kt:51-63）→ 偏好读取(77-78) → `CarPlayHostActivity.kt:143/176` 写入 `config.transport` → `CarPlayTransport` 二态枚举(RuntimeConfig.kt:9-12)。
- 调度主干 `CarPlayController.kt` 双向分流(:435 有线 / :454 无线 / :1081 启动 / :615-625 拆除)。
- 分支相对 origin/main 改动全部为「新增/扩展」：compat 桥接层(UsbPermissionCompat/NetworkCompat/BluetoothCompat/ApiLevel) 保住两条路径；无线栈重写(ExternalWifiConnectionManager 新增、CarPlayDiscovery +258、WifiP2pLegacyChannelsApi17 新增)。
- 结论：两条路径均完整可达、有测试覆盖（WIRED/WIRELESS 用例皆有）。唯一需实机验证点：API17 的 Wi-Fi P2P 5GHz 受限，但有多后端兜底(LOCAL_ONLY_HOTSPOT/MANUAL/EXISTING_WIFI)。
