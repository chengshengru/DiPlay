# 2026-10-16 第九轮续：NCM 桥诊断增强（屏幕/诊断报告可见卡点）+ 排查纠偏

## 纠正两个早前假设

# 2026-10-16 第十轮：iPhone「每次都要信任」根因 + 稳定主机身份修复

## 用户新线索
- 「而且两次都要在 iPhone 上信任」——决定性：配对记录未稳定复用，每次重弹 Trust 且连接退出。

## 根因定位（读源码坐实）
- `CarPlayController` 在 `CarPlayHostActivity.startCarPlay`（:5145→:5208 `val next = CarPlayController(...)`）**每次连接新建实例**。
- `hostId`/`systemBuid` 是控制器 `val`（:212-213，原 `UUID.randomUUID()`）——**每次连接重新随机生成**，仅在 `saveLockdownRecord` 里作为完整配对记录的一部分落盘。
- `runStack`（:2339-2340）：`savedPairRecord = loadPairRecord()`；`pairRecord = savedPairRecord ?: pairNewRecord(...)`。配对客户端 `LockdownCarKitClient.open`（:39-40）与 `LockdownPairingClient.pair`（:57-58）都读 `pairRecord.hostId/systemBuid`（来自记录），不读控制器 fresh 值——设计上若记录能 load 则不重弹 Trust。
- 因此「每次都要信任」= `loadPairRecord()` 返回 null（记录没存下来 / restore 抛异常 / 被拒后 clear）⇒ `pairNewRecord` 用**全新 HostID** ⇒ iPhone 视为新电脑 ⇒ 重弹 Trust。
- `saveLockdownRecord`（:1372-1384）原用 `.apply()`（异步落盘）：连接挂 5 分钟后 `fail()`→退出，若进程在异步写完成前死亡，**记录丢失** → 下次 null → 重弹。
- `clearPairRecord`（:2388）只在「已存记录被 iPhone 拒（InvalidPairRecord/InvalidHostID）」时触发，随后 `pairNewRecord` 又用 fresh HostID → 拒绝-重配对循环也会反复重弹。

## 修复（框架层，允许；非爬虫/非KSPlayer）
| 位置 | 改动 |
|---|---|
| `AirPlayPersistence.kt` | 新增稳定身份键 `KEY_HOST_IDENTITY_HOST_ID`/`KEY_HOST_IDENTITY_SYSTEM_BUID` + `getStableHostId`/`getStableSystemBuid`（`getOrCreateStableIdentity`：首次生成 `commit()` 落盘，之后复用），import `java.util.UUID`/`Locale` |
| `AirPlayPersistence.kt` `saveLockdownRecord` | `.apply()` → `.commit()`（同步落盘，配对记录必在退出/进程死前写稳） |
| `CarPlayController.kt` | `hostId`/`systemBuid` 由随机 `val` 改为 `AirPlayPersistence.getStableHostId(appContext)`/`getStableSystemBuid(appContext)`；import `AirPlayPersistence`；移除不再使用的 `import java.util.Locale`（零警告门禁） |
| `CarPlayController.kt` `runStack` | 诊断 log 增加 `hostId.take(8)` 前缀（`wired using saved/created ... hostId=xxxx`），便于下次侧载比对两次连接 HostID 是否一致 |

## 修复逻辑与向后兼容
- 稳定 HostID 与完整配对记录**解耦**：即便记录因任何原因丢失，主机身份仍稳定，避免「新电脑」反复信任。
- 拒绝-重配对路径（:2388-2390）现用**稳定** HostID 重配，杜绝「每次拒绝都换新 HostID」循环。
- 旧版已存记录（含旧随机 HostID）仍会被 `loadPairRecord` 正常复用，仅当该记录被清/丢失时才启用新稳定身份——无回归。
- `commit()` 返回值被丢弃，函数体返回 Unit，类型兼容。
